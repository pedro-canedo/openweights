# OpenWeights 0.18.2

## Português

- **Modelos guardados em subpasta voltam a aparecer.** Repositórios grandes do
  Hugging Face separam cada quantização numa pasta (`UD-Q2_K_XL/`), o download
  preservava esse caminho e a biblioteca parava um nível antes. O modelo ficava
  no disco, íntegro e invisível. Nada precisa ser baixado de novo: abra
  **Meus Modelos** e ele estará lá.
- **O download passa a usar a linha inteira.** Os shards de um mesmo modelo
  baixam juntos, e cada arquivo grande é dividido em faixas com uma conexão
  cada, sobre HTTP/1.1 — em HTTP/2 as faixas voltariam a dividir um cano só.
  Medido de ponta a ponta: o mesmo arquivo saiu de 41,9 s para 21,9 s, com
  pico de 51,5 MB/s.
- **O atalho na Área de Trabalho volta a aparecer no Windows.** Ele nascia só
  em instalação nova; quem instalou uma vez e desde então só atualiza nunca
  ganhava um, e tinha de procurar o app no menu Iniciar. Atualizar para esta
  versão cria o atalho. Quem apagou o seu de propósito continua sem ele.
- Downloads interrompidos continuam retomando de onde pararam, agora faixa por
  faixa. Um `.part` de versão anterior retoma no formato antigo, sem recomeçar.

O ganho depende da distância até o servidor: quem já saturava a linha com uma
conexão vê pouca diferença. Arquivos abaixo de 16 MB continuam com uma
conexão só, porque dividir os pequenos custa mais do que rende.

## English

- **Models kept in a subfolder are visible again.** Large Hugging Face
  repositories put each quantization in its own folder (`UD-Q2_K_XL/`), the
  downloader preserved that path, and the library stopped one level short. The
  model sat on disk, complete and invisible. Nothing needs downloading again:
  open **My Models** and it is there.
- **Downloads now use the whole connection.** Shards of the same model download
  together, and each large file is split into ranges with one connection each,
  over HTTP/1.1 — on HTTP/2 the ranges would share a single pipe again.
  Measured end to end, the same file went from 41.9 s to 21.9 s, peaking at
  51.5 MB/s.
- **The desktop shortcut is back on Windows.** It was only created on a fresh
  install, so anyone who installed once and has updated ever since never got
  one and had to find the app in the Start menu. Updating to this version
  creates it. Anyone who deleted theirs on purpose still won't get one.
- Interrupted downloads still resume where they stopped, now range by range. A
  `.part` from an earlier version resumes in the old format rather than
  starting over.

The gain depends on the distance to the server: anyone already saturating their
line with a single connection will see little change. Files under 16 MB keep
using one connection, because splitting small ones costs more than it returns.
