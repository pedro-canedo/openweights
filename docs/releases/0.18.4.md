# OpenWeights 0.18.4

## Português

- **Baixar um modelo não trava mais o computador.** Desde a 0.18.2 o download
  usa várias conexões em paralelo, e no Windows isso destravou um detalhe caro
  do NTFS: escrever longe do início de um arquivo recém-criado faz o sistema
  zerar fisicamente tudo que vem antes. Com oito conexões começando juntas,
  eram vários gigabytes de escrita inútil — o app parava de responder, o botão
  de pausa não funcionava e as outras aplicações travavam junto, porque o
  disco é do sistema inteiro. Marcando o arquivo como esparso, a mesma escrita
  passou de 9,54 s para 0,51 ms.
- **A barra de status cabe em uma linha em qualquer resolução.** Os nomes
  escritos ("ENERGIA", "DISCO") ocupavam mais espaço que os números e faziam a
  barra quebrar em duas linhas nas telas menores. Agora cada medidor tem um
  pictograma, e o nome aparece ao passar o ponteiro.

Quem viu o travamento sumir sozinho não estava enganado: o zeramento acontece
uma vez por arquivo, na primeira escrita distante do início, e depois passa.
Downloads já em andamento não precisam ser reiniciados.

## English

- **Downloading a model no longer freezes the computer.** Since 0.18.2 the
  downloader uses several parallel connections, and on Windows that exposed an
  expensive NTFS detail: writing far into a freshly created file makes the
  system physically zero everything before it. With eight connections starting
  at once, that meant gigabytes of pointless writing — the app stopped
  responding, the pause button did nothing, and other applications froze too,
  because the disk belongs to the whole system. Marking the file sparse took
  the same write from 9.54 s to 0.51 ms.
- **The status bar fits on one line at any resolution.** The written labels
  ("ENERGIA", "DISCO") took more room than the numbers themselves and pushed
  the bar onto a second line on smaller screens. Each meter now has a
  pictogram, with the name on hover.

Anyone who saw the freeze disappear on its own was not imagining it: the
zeroing happens once per file, on the first distant write, and then it is over.
Downloads already in progress do not need restarting.
