## Português

- O AgenticOw não pede mais a chave da DeepSeek ao abrir. Ele não tem provedor próprio: o provedor nativo da DeepSeek e a busca na web dela ficam fora do build, e os modelos vêm só das fontes do OpenWeights — Servidor Local, OpenRouter e 9router.
- No ar e sem modelo nenhum, a tela do AgenticOw mostra essas três fontes no lugar de uma interface vazia, com o que cada uma tem agora e o próximo passo. Com modelo na biblioteca, o Servidor Local sobe dali mesmo; o resto leva à aba certa de Fontes. A interface volta assim que o primeiro modelo chega.
- O modelo padrão do AgenticOw passa a ser o primeiro modelo do app — o local, senão o OpenRouter, senão o 9router —, inclusive para quem trouxe do DeepSeek Harness um padrão apontando para a DeepSeek.
- A página de Modelos do AgenticOw avisa que os modelos vêm do OpenWeights e deixa de oferecer "Adicionar provedor", que a lista do app substituiria.
- A ferramenta `web_search` responde ao modelo que a busca não está disponível; a `web_fetch` continua lendo as páginas que ele recebe.

## English

- AgenticOw no longer asks for a DeepSeek key when it opens. It has no provider of its own: the native DeepSeek provider and its web search are out of the build, and models come only from OpenWeights' sources — the Local Server, OpenRouter and 9router.
- Running with no model at all, the AgenticOw screen shows those three sources instead of an empty interface, with what each has right now and the next step. With a model in the library, the Local Server starts right there; the rest opens the matching tab in Sources. The interface comes back as soon as the first model arrives.
- AgenticOw's default model is now the app's first model — local, else OpenRouter, else 9router — including for anyone who brought over from the DeepSeek Harness a default pointing at DeepSeek.
- AgenticOw's Models page says models come from OpenWeights and no longer offers "Add provider", which the app's list would replace.
- The `web_search` tool tells the model search is unavailable; `web_fetch` still reads the pages it is given.
