# OpenWeights 0.17.0

## Português

- Chat mais fluido: histórico virtualizado, streaming em intervalos de 50 ms e
  destaque de código ao concluir. Cancelar preserva respostas parciais.
- Espera compreensível: fases explícitas, tempo até primeiro token e primeira
  resposta, métricas salvas na conversa e dados ausentes identificados.
- Fila local com capacidade configurada, retries limitados e títulos automáticos
  com prioridade menor. Provedores remotos continuam independentes da fila local.
- **Testar uma configuração melhor** em Servidor Local → Desempenho: aquecimento,
  três medições por configuração, mediana e variação, aplicar e restaurar.
  Contexto, quantização e esforço de raciocínio são preservados.

A CPU de renderização caiu 93,7% no cenário sintético de desenvolvimento com
500 mensagens. Isso não representa aumento de tokens/s. A confirmação com nove
medições de inferência por cliente no Windows ficou dentro do limite de 5% de
não regressão nas medianas. [Metodologia e limitações](https://github.com/pedro-canedo/openweights/blob/v0.17.0/docs/performance-0.17.0.md).

O comparador exige servidor ocioso e deixa a API local temporariamente
indisponível. Evite clientes externos e outros programas usando a GPU.
Conversas antigas continuam legíveis; a migração do SQLite é aditiva.

## English

- Smoother chat with virtualized history, 50 ms streaming updates and deferred
  syntax highlighting. Cancellation preserves partial responses.
- Explicit waiting phases, first-token/first-answer timings and persistent
  run metrics. Missing engine metrics are shown as unavailable.
- Capacity-aware local scheduling, bounded retries and lower-priority title
  generation. Remote providers remain independent of the local queue.
- **Test a better configuration** under Local Server → Performance: warmup,
  three runs per configuration, median/range, apply and restore. Context,
  quantization and reasoning effort are preserved.

The synthetic development fixture reduced median React render CPU by 93.7%
with 500 history messages. This does not claim faster inference. A confirmation
with nine inference samples per client on Windows met the 5% median
non-regression threshold; first-token jitter remains documented.
The comparator requires an idle server and temporarily stops the local API;
avoid external clients and other GPU workloads while testing.

## Installation

Installers are attached for Windows x64, macOS universal and Linux x64.
Existing installations receive the signed updater metadata.

The binaries have no paid code-signing certificate. Windows may show SmartScreen
(More info → Run anyway); on macOS allow the app in System Settings → Privacy
& Security after the first attempt. The macOS bundle is ad-hoc signed.
On first launch, OpenWeights downloads the llama.cpp runtime matching your GPU.
