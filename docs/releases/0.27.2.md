destaque: O OwCLI não fica mais preso em "high demand" depois de uma chamada de ferramenta cortada
---

## Português

- **O agente OwCLI se recupera quando o modelo é cortado no meio de uma chamada de ferramenta.** Com uma tarefa grande (um arquivo inteiro escrito de uma vez), a geração podia parar no meio dos argumentos da chamada. O motor entrega essa chamada cortada como se estivesse completa, o agente a guarda no histórico e, a partir daí, cada pedido levava HTTP 500 (`Failed to parse tool call arguments as JSON`): a tela ficava em "We're currently experiencing high demand" e nem "continue" adiantava. Agora o app troca a chamada cortada, no histórico, por um aviso que guarda o começo do que o modelo escreveu; o modelo vê que a chamada não rodou e refaz em partes menores. Reproduzido com o llama-server real.
- O painel de logs (`Ctrl+Shift+L`) registra quando isso acontece.

## English

- **The OwCLI agent recovers when the model is cut off in the middle of a tool call.** On a big task (a whole file written at once), generation could stop in the middle of a call's arguments. The engine hands that call back as if it were complete, the agent keeps it in its history and, from then on, every request got HTTP 500 (`Failed to parse tool call arguments as JSON`): the screen sat on "We're currently experiencing high demand" and even "continue" did nothing. Now the app replaces the cut-off call, in the history, with a notice that keeps the start of what the model wrote; the model sees the call did not run and redoes it in smaller pieces. Reproduced with the real llama-server.
- The logs panel (`Ctrl+Shift+L`) records when this happens.
