## Português

- A janela do painel do DeepSeek Harness remontava o endereço a partir da porta. Agora ela abre o endereço inteiro que o próprio harness imprime ao subir, e a verificação de que ele está pronto consulta esse mesmo endereço.
- Isso prepara o app para as próximas versões do harness, que anunciam o endereço com uma credencial de sessão e recusam a página sem ela. A versão do harness que o app instala continua a mesma: a publicada depois dela não conclui a inicialização nos nossos testes.

## English

- The DeepSeek Harness panel window used to rebuild the address from the port. It now opens the whole address the harness itself prints on startup, and the readiness check queries that same address.
- This prepares the app for the next harness releases, which announce the address with a session credential and refuse the page without it. The harness version the app installs is unchanged: the one published after it does not finish starting up in our tests.
