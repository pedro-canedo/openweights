# OpenWeights 0.19.1

## Português

- **A otimização mostrava uma velocidade de geração alta demais** em máquinas
  com especulação ligada. O prompt longo do teste era o mesmo parágrafo
  repetido dezenas de vezes, e a especulação por n-grama encontrava a
  continuação dentro do próprio prompt: a taxa subia várias vezes e o número
  descrevia o texto de teste, não o modelo. Num caso real, a tela dizia
  129 tok/s onde o chat entregava 31.
- O prompt longo passa a ter enunciados e funções variados, e o identificador
  do teste mudou para `v3` — uma medição feita antes desta versão não é
  comparável com uma feita agora.

Se você tinha medições anteriores, refaça a otimização: os números novos serão
mais baixos e mais próximos do que a conversa entrega de verdade. A comparação
entre as opções continua válida, porque todas eram medidas do mesmo jeito.

## English

- **Optimization reported a generation speed that was too high** on machines
  with speculative decoding enabled. The test's long prompt was the same
  paragraph repeated dozens of times, and n-gram speculation found the
  continuation inside the prompt itself: the rate multiplied and the number
  described the test text rather than the model. In a real case the screen
  said 129 tok/s where chat delivered 31.
- The long prompt now varies its tasks and function shapes, and the workload
  identifier moved to `v3` — a measurement taken before this version is not
  comparable with one taken now.

If you have earlier measurements, run the optimization again: the new numbers
will be lower and closer to what a conversation actually delivers. The
comparison between options stays valid, since all of them were measured the
same way.
