# OpenWeights 0.20.0-rc.1

## Português

- **Treinar** abre o novo Studio opcional: dados, treinamento e resultado na interface do desktop.
- Um único livro pode ser preparado com treino, validação e teste separados. Conversas preservam mensagens reais; prosa não vira perguntas e respostas artificiais.
- Runtime Windows privado com Python, PyTorch/CUDA, QLoRA e ferramentas GGUF; instalação sob demanda com catálogo assinado e verificação SHA-256.
- OCR local opcional com Tesseract, português e inglês. PDFs mistos aproveitam o texto nativo; páginas já processadas são reutilizadas na retomada.
- Receita inicial Qwen3-0.6B, benchmark, treino curto, avaliação e GGUF Q4_K_M automático. O resultado entra na biblioteca e pode ser aberto no chat.
- Parada explícita do motor antes do treino, exclusão de GPU, cancelamento cooperativo, checkpoints verificados e importação por cópia dos dados do MVP.

**Release candidata:** treinamento e exportação foram exercitados em Windows com RTX 3090. Um experimento curto não garante respostas corretas sobre os documentos. O OCR foi avaliado numa amostra de livro rasterizado e PDF misto, não em todos os tipos de digitalização. O treinamento desta versão é destinado a Windows x64 com NVIDIA; chat continua disponível nas plataformas existentes. Esta candidata não substitui automaticamente a versão estável pelo updater.

## English

- **Train** opens the optional Studio: data, training and results inside the desktop interface.
- A single book can produce separate training, validation and test partitions. Conversations preserve real messages; prose is never converted into fabricated question/answer pairs.
- Private Windows runtime with Python, PyTorch/CUDA, QLoRA and GGUF tools; on-demand installation with signed catalogs and SHA-256 verification.
- Optional local Tesseract OCR with Portuguese and English. Mixed PDFs reuse native text and preparation resumes from completed pages.
- Initial Qwen3-0.6B recipe with benchmark, short training, evaluation and automatic Q4_K_M export. The model is published into the library and can be opened in chat.
- Explicit engine stop before training, GPU exclusion, cooperative cancellation, verified checkpoints and copy-based import from the MVP.

**Release candidate:** training and export were exercised on Windows with an RTX 3090. A short experiment does not guarantee factual answers about documents. OCR was tested on a rasterized book sample and a mixed PDF, not every kind of scan. Training targets Windows x64 with NVIDIA; chat remains available on existing platforms. This candidate does not automatically replace the stable version through the updater.
