## Português

**Corrigido**

- **O número de conversas simultâneas de um modelo passa a valer.** O `--parallel` global ia na linha de comando do servidor, e a linha de comando vence a seção do modelo no Router: o valor escolhido para um modelo era ignorado (medido no llama.cpp b10441). Agora, com o INI do Router, o número global vai para a seção `[*]` e o modelo que pediu outro recebe o dele.

**Ver o que está rodando**

- **Painel de logs** (`Ctrl+Shift+L`, botão na barra de status ou paleta): o llama-server, o decisor, o 9router, o gateway do OwCLI e o próprio OpenWeights num lugar só. Filtra por origem e por texto, pausa, copia, salva na pasta `exports` do app e limpa. O que o servidor disse enquanto subia continua lá quando você abre o painel depois.
- **A prévia do comando** de Servidor Local › Desempenho sai do recolhido: mostra o comando exato, o ambiente e o INI, diz se o que está rodando é o que está configurado (**Mudanças pendentes** quer dizer que reiniciar muda alguma coisa), copia como comando de shell com a chave da API mascarada e abre o INI na pasta.
- **Ajustar para esta máquina** e os números de concorrência (modelos simultâneos, conversas ao mesmo tempo) ficam em Servidor Local › Desempenho, num lugar só. O botão de Meus Modelos leva até lá com o painel já aberto.
- Cada ajuste manual do catálogo de flags que difere do padrão do llama.cpp ganha o selo **Modificada** e um **↺ Padrão** que o desfaz.

**Erros que dizem o que fazer**

- O texto cru (`HTTP 500: …`) dá lugar a um cartão com o que houve, por quê e o botão que resolve: instalar o motor, abrir o Servidor Local ou as Fontes, começar uma conversa nova, tentar de novo. O texto original fica recolhido e copiável. Vale no Chat, na biblioteca (que falhava parecendo vazia), nos downloads, no primeiro uso, no Servidor Local e nas Fontes.
- **Apagar uma mensagem** some na hora e dá cinco segundos para **Desfazer**; só então o app apaga de verdade.
- **Cancelar ou descartar um download** pergunta antes e diz quantos gigabytes se perdem. Excluir um modelo também mostra o tamanho.
- **O AgenticOw só baixa depois do seu clique**, com o tamanho na frente (o runtime e, se preciso, o Node.js portátil).

**Configuração e biblioteca**

- **Backup da configuração** (Configurações): exporta servidor, perfis por modelo, presets e escolhas dos provedores em JSON, e importa em outra máquina, confirmando antes e dizendo o que o arquivo traz. Chaves e senhas só vão se você marcar.
- **Meus Modelos em tabela**: ordena por nome, origem, quantização ou tamanho; seleciona vários e exclui de uma vez, com o total que volta ao disco; abre a pasta de cada modelo.
- **Chat, no modo Avançado**: `min_p`, penalidades de repetição, presença e frequência, semente, sequências de parada, resposta em JSON (com esquema opcional) e **Usar os padrões do servidor**. **Copiar requisição** entrega a chamada do chat como cURL, Python ou JavaScript, sem a chave de API.
- **Glossário**: um **?** ao lado de quantização, GGUF, contexto, VRAM, tok/s, MoE, cache KV e slot explica cada termo em palavras comuns.

**OwCLI**

- **O comando `owcli` em qualquer terminal do sistema** (Configurações, opt-in): liga o `owcli` ao PATH sem tocar em nada que não seja do app. Ao atualizar o agente, o comando passa para a versão nova antes de a antiga ser apagada, e uma versão em uso não é apagada.

## English

**Fixed**

- **A model's number of simultaneous conversations now takes effect.** The global `--parallel` went on the server command line, and the command line wins over a model's section in the Router: the value chosen for a model was ignored (measured on llama.cpp b10441). Now, with the Router INI, the global number goes to the `[*]` section and a model that asked for another gets its own.

**Seeing what is running**

- **Logs panel** (`Ctrl+Shift+L`, the status bar button or the palette): llama-server, the decider, 9router, the OwCLI gateway and OpenWeights itself in one place. It filters by source and text, pauses, copies, saves to the app's `exports` folder and clears. What the server said while it started is still there when you open the panel later.
- **The command preview** in Local Server › Performance leaves its collapsed section: it shows the exact command, the environment and the INI, says whether what is running is what is configured (**Pending changes** means a restart will change something), copies as a shell command with the API key masked and opens the INI in its folder.
- **Adjust for this machine** and the concurrency numbers (concurrent models, conversations at once) live in Local Server › Performance, in one place. The button in My Models takes you there with the panel already open.
- Every manual flag in the catalog that differs from the llama.cpp default gets a **Modified** badge and a **↺ Default** that undoes it.

**Errors that say what to do**

- Raw text (`HTTP 500: …`) gives way to a card saying what happened, why and the button that fixes it: install the engine, open Local Server or Sources, start a new conversation, try again. The original text stays collapsed and copyable. It applies in Chat, in the library (which used to fail looking empty), in downloads, on first run, in Local Server and in Sources.
- **Deleting a message** removes it at once and gives five seconds to **Undo**; only then does the app really delete it.
- **Cancelling or discarding a download** asks first and says how many gigabytes are lost. Deleting a model also shows its size.
- **AgenticOw only downloads after your click**, with the size up front (the runtime and, if needed, the portable Node.js).

**Configuration and library**

- **Configuration backup** (Settings): exports server, per-model profiles, presets and provider choices as JSON, and imports on another machine, confirming first and saying what the file brings. Keys and passwords only go if you tick the box.
- **My Models as a table**: sorts by name, source, quantization or size; select several and delete them at once, with the total that returns to disk; open each model's folder.
- **Chat, in Advanced mode**: `min_p`, repeat, presence and frequency penalties, seed, stop sequences, JSON answers (with an optional schema) and **Use the server's defaults**. **Copy request** gives the chat's call as cURL, Python or JavaScript, without the API key.
- **Glossary**: a **?** next to quantization, GGUF, context, VRAM, tok/s, MoE, KV cache and slot explains each term in plain words.

**OwCLI**

- **The `owcli` command in any system terminal** (Settings, opt-in): puts `owcli` on the PATH without touching anything that is not the app's. When the agent updates, the command moves to the new version before the old one is deleted, and a version in use is never deleted.
