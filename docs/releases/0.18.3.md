# OpenWeights 0.18.3

## Português

- **"Descobrir" volta a funcionar depois que a sessão do Hub expira.** O login
  do Hugging Face dura horas; a busca, o README e a lista de quantizações
  usavam o token de quando a janela abriu e nunca o renovavam. Vencido o
  prazo, o Hub respondia 401 e a tela virava "Algo deu errado" — um catálogo
  público escondido atrás de uma sessão vencida. As três telas passam a
  renovar a sessão antes de perguntar, e a busca ainda repete sem token se ele
  for recusado: a lista de modelos é pública e não depende de estar logado.
- **O cartão de erro passa a dizer o que deu errado.** "Algo deu errado" sem o
  motivo não chega a quem poderia consertar. Agora há um "detalhes técnicos"
  com a mensagem real.

Nada precisa ser refeito: quem estava com a sessão vencida volta a ver a lista
ao abrir esta versão. Entrar de novo no Hugging Face continua sendo necessário
só para baixar modelos com licença aceita.

## English

- **"Discover" works again after the Hub session expires.** A Hugging Face
  login lasts hours; search, the README and the quantization list used the
  token from when the window opened and never refreshed it. Once it expired,
  the Hub answered 401 and the screen became "Something went wrong" — a public
  catalogue hidden behind a stale session. All three now refresh the session
  before asking, and search additionally retries without the token if it is
  refused: the model list is public and does not depend on being signed in.
- **The error card now says what went wrong.** "Something went wrong" with no
  reason never reaches anyone who could fix it. There is now a technical
  details section with the real message.

Nothing needs redoing: anyone with an expired session sees the list again on
opening this version. Signing in to Hugging Face is still only needed to
download models behind an accepted licence.
